# BAA/DSA readiness checklist (template)

Use this before signing site sponsor agreements involving PHI.

## Legal packet
- [ ] Signed MSA / Order Form
- [ ] BAA (US) or DSA/DPA (Canada/other jurisdictions) executed
- [ ] Subprocessor list attached
- [ ] Security exhibit attached (controls + incident response)

## Security commitments
- [ ] Named security owner and contact method
- [ ] Breach/incident notification process defined
- [ ] Access control and least-privilege model documented
- [ ] Backup and restore drill evidence retained

## Data handling commitments
- [ ] Data flow mapped (ingest, storage, sharing, deletion)
- [ ] Retention period per tenant/customer defined
- [ ] Deletion/export workflow documented
- [ ] Cross-border processing terms explicitly acknowledged
